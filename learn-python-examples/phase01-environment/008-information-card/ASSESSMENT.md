# 第一阶段综合验收

[返回课程](README.md) · [返回阶段导航](../README.md)

本表是读者自己的验收任务，不预填通过。仓库的自动验证不能替代读者独立完成。

| 项目 | 你要做什么 | 通过标准 | 自己的记录 |
| --- | --- | --- | --- |
| 独立创建 | 在新位置从空文件完成初版 | 输出逐行一致，不靠直接运行现成答案 | 待填写 |
| 输出预测 | 调整行序、去掉源码空行，再加空字符串输出 | 能在运行前准确说明变化 | 待填写 |
| 两版保留 | 完成渠道、城市和状态变更 | 初版仍能独立运行，第二版符合新需求 | 待填写 |
| 路径理解 | 从本课和步骤目录分别运行第二版 | 文件相同、输出相同，解释每段相对路径 | 待填写 |
| 模式理解 | 对比裸字符串的交互回显与脚本表现 | 不把提示符抄进源码，解释为什么脚本可无输出 | 待填写 |
| 故障定位 | 复现错误路径、语法错误，再复查 005 的名字错误 | 分清文件定位、语法期、运行期，写明修复原因 | 待填写 |
| 环境归属 | 明确调用本课环境并运行诊断 | prefix 指向本课环境；与基础入口对照有证据 | 待填写 |
| IDE 对照 | 用 006 方法核对编辑器入口 | 实际操作后记录；不能操作则诚实写未实测 | 待填写 |
| 运行说明 | 写一份别人能跟随的 RUNBOOK | 起点、准备、命令、预期结果与常见错误齐全 | 待填写 |
| 独立变式 | 不看答案完成 exercises 的新需求 | 内容、行序、空行都正确，并说明改动点 | 待填写 |

未通过的项目回到对应课：输出 002，路径 003，交互 004，异常 005，解释器 006，环境 007。完成后再进入阶段 02，不需要为通过验收引入当前未教的语法。
