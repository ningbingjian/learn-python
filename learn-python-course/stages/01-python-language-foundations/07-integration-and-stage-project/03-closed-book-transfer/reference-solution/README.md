# 截止信息迁移题参考解

这是一份完整练习答案，不是第八个主线里程碑。请先完成[闭卷题面](../)，再阅读[设计判断](../SOLUTION.md)。

Python 3.14，仅标准库。在本目录运行：

```bash
python3.14 -m task_tracker
python3.14 -m unittest discover -s tests -v
```

在最终版 add/edit 的备注之后额外输入截止天数，空白无截止，0 今天到期。新增 list --priority（1 最高、同优先级稳定顺序）和 list --due（今天到期且未完成）。其他命令、退出策略、稳定 ID 与内存生命周期保持不变。

tests 保留对象与导入契约，并以新的录入协议验证新旧命令组合、非法截止输入恢复、排序不改源集合、编辑整体性和新提示处 EOF。目录内实现与测试完全独立，不导入主线源码，便于在自己的练习副本中对照。
