# Python 从入门到深入：示例驱动学习路线

## 这条路线怎样学习

面向宁炳剑个人学习：用中文讲清原理，用完整注释引导抄代码，用可观察的结果验证理解。以 Python 语言与后端开发为主线，同时保留自动化、数据分析和底层机制的广度。这里的“深入”以能独立解决问题为标准，不以抄完数量或学完若干周承诺“精通”。

**当前版本是规划：24 个阶段、192 个示例，课程正文与源码尚未生成。** 每个编号可继续拆成多个演进步骤；一节较难的主题可以分多次完成。没有源码链接的条目不是已完成课程。

每个阶段按“基础用法 → 机制与边界 → 组合实践”推进。每个示例按“理论 → 实操（边抄边解释原理）→ 小总结”组织；理论结束和整课结束也分别总结。详细要求见 [AGENTS.md](AGENTS.md)。

## 顺序与深度

- 第一轮：01—11，建立语言与工程基础。不要因有 Java 经验跳过引用、默认参数、模块导入和对象协议。
- 第二轮：12—18，完成 HTTP、数据库、接口、并发、任务和部署主线。13 可在 11 后与 12 独立学习，15 前补齐两条支线。
- 19—20 是选学拓展：在满足前置条件后按需要插入，不阻塞后端主线。
- 第三轮：21—23，深入设计、通信协议、性能和源码。23 放到能写、能测、能排错之后。
- 24 是贯穿式项目区：达到某个项目的前置要求即可开始，不必等全部阶段结束。

每个阶段先完成表中的可运行目标，再做“阶段验收”。不会解释的步骤回看理论，不能只通过照抄把报错消掉。涉及新库或新版本时，课程生成时再选择并锁定实际验证的依赖；路线不强制所有示例使用同一个巨大的环境。
