# Python 示例学习区

这是一个 Python 示例学习区：从零开始学 Python，通过“理解原理 → 跟着讲解抄代码 → 运行观察 → 修改验证”逐步掌握语言和实际开发。

有 Java 基础可以帮助理解，但课程不能默认已经懂 Python。首次出现的 Python 语法、工具、参数、目录和运行机制都需要解释。

## 从哪里开始

1. 阅读 [完整学习路线](ROADMAP.md)，了解阶段顺序和每个示例的目标。
2. 后续从 `01-001` 开始生成并学习示例。一次学一个，不需要一次抄完整个阶段。
3. 每个示例先读核心理论，再按步骤创建文件、抄写代码和命令；每一步运行并对照结果。
4. 完成变式练习，再阅读小总结和本课总结。能解释、能改动、能排错，才算学会。

## 学习方式

每课使用“理论 → 实操（伴随原理讲解）→ 小总结”，整课末尾再给一次课程总结。不能只列操作步骤，也不能只有空泛概念。

抄写是理解程序的过程，不是机械重复。可以手动输入，也可以复制完整代码后逐行阅读、修改与验证。每个源码文件都要有详细中文注释，不把必须理解的知识只藏在文档里。

示例优先使用简单生活场景，基础稳定后逐渐引入广告订单、城市曝光、接口超时、日志分析等熟悉的业务。所有数据均为教学模拟数据。

后续生成、修改示例必须遵守 [示例编写规范](AGENTS.md)。基础示例使用标准库、单文件起步；真正需要第三方依赖或服务时才引入，并详细解释配置。
