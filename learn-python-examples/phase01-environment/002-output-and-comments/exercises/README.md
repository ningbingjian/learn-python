## 任务

在自己的 exercises/main.py 输出标题、空行、城市、编号、状态，顺序为标题、空行、城市、编号、状态。标题固定为“# 模拟订单信息”。城市用南京，编号用 DEMO-003，状态用待投放。不要改动两步源码。验收：5 行（含 1 个空行），字符串内的井号保留，源码注释不显示。

预期输出（先按需求独立实现，不必先看参考源码）：

```text
# 模拟订单信息

城市：南京
订单编号：DEMO-003
状态：待投放
```

先独立完成，记录自己的命令、观察结果与原因；记录使用相对目录或虚构路径，不提交个人绝对路径。完成后再阅读 [参考解答](SOLUTION.md)。
