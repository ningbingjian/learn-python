# 第一步交互记录

[返回课程](../README.md)

从本课目录的 shell 使用下列入口之一进入交互环境。

```bash
# bash/zsh：不传脚本，进入交互模式。
python3
```

```powershell
# PowerShell：使用已检查成功的入口。
python
```

逐条输入，不抄提示符：

```python
# 先观察表达式回显。
"模式实验"
# 再观察函数的显式输出。
print("模式实验")
# 最后退出。
exit()
```

下面是省略版本横幅的示意会话，用来辨认输入与输出，不能复制到脚本：

```text
>>> "模式实验"
'模式实验'
>>> print("模式实验")
模式实验
>>> exit()
```

前三个输入的含义见课程正文。新版本交互界面可能有颜色、不同的编辑方式；核心对照是有引号的字符串表示与不带界定引号的输出。会话不生成业务文件；退出后可重新进入重复实验。
